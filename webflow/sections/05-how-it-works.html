How generative AI works

Most modern generative AI systems follow the same basic process.

An imperfect but useful way to think of language models is as prediction machines. When building a sentence, the system predicts the most likely next word, then the one after that, based on patterns learned from an enormous amount of training text.

Phase 1: Building the model

01

Training data

AI developers feed vast amounts of text, images, audio or code into the model: a neural network that acts as a digital pattern-recognition engine.

02

Learning

The model analyzes the data and finds recurring relationships and structures.

03

The model

Training produces a web of mathematical patterns and probabilities, not a searchable database of facts. The model uses these patterns to turn raw probabilities into natural, human-like language.

The trained model is ready to use

Phase 2: Using the model

04

Prompt

People give the model a prompt: a question, an instruction, an audio recording, a photo and so on.

05

Prediction

The model uses the learned patterns to generate a likely output. It builds the response one small piece (a token) at a time, each piece shaping the next, until it is complete.

06

Response

The result is newly generated content that responds to the prompt, also called synthetic content: an answer, an image, a video, synthesized speech and so on.
