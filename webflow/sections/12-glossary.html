AI glossary

AI agent

An AI system that is given a goal and works towards it by itself, planning steps and using tools such as web search or other apps.

Algorithm

A set of instructions a computer follows to complete a task or solve a problem.

Artificial intelligence (AI)

A broad category of technologies that can perform tasks that typically require human intelligence.

Bias

Systematic skew in AI outputs, often inherited from patterns in the training data.

Deep learning

A kind of machine learning that uses neural networks with many layers. It powers most modern AI, including generative AI.

Diffusion

A way of generating images: the model starts from random noise and removes it step by step until a picture that matches the prompt appears.

Generative AI

AI that creates new content such as text, images, audio or code, rather than only analyzing existing data.

Hallucination

When an AI system generates false or fabricated information that sounds plausible.

Large language model (LLM)

A type of generative AI trained on large amounts of text to process and produce language.

Machine learning

A subset of AI in which systems learn patterns from data rather than following explicit rules.

Model

The trained core of an AI system: a large set of mathematical patterns learned from data, used to calculate probabilities and predict outputs.

Neural network

A system of connected mathematical units, loosely inspired by the brain, that learns by adjusting the strength of the connections between them.

Pattern

A regularity or structure found in data that can be used to make predictions or decisions.

Prompt

The input or instruction given to an AI system to generate a response.

Reasoning model

An LLM trained to work through a problem in steps before giving its final answer.

Symbolic AI

The oldest approach to AI, where people write the rules and facts a system uses to make decisions.

Synthetic content

Text, images, audio or video created by an AI system rather than captured or made by people.

Token

A small piece of text, such as a word or part of a word, that a language model reads and predicts one at a time.

Training data

The data used to teach an AI system the patterns it will later use to generate output.

Transformer

The neural network design, introduced in 2017, behind today’s large language models. It weighs how every word in a text relates to every other word.
